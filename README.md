# Interactive CISO MindMap 2026

An interactive, searchable web version of Rafeeq Rehman's **CISO MindMap 2026 – What do Security Professionals Really Do?**, with a short explanation for every topic and key controls and requirements for the most important ones.

**Live site:** https://cmorell.github.io/ciso-mindmap/

## What it does

- **Collapsible branches.** The 12 top-level areas open and close on click. A badge shows how many topics each branch contains.
- **Explanations.** Each of the 371 topics has a one or two sentence description of what it covers.
- **Controls and requirements.** 120 topics list the controls behind them, with references to ISO/IEC 27001:2022, NIST CSF 2.0 and SP 800 publications, CIS Controls v8, PCI DSS v4.0, GDPR, DORA, SEC rules, OWASP and MITRE. An amber dot marks these topics on the map.
- **Search.** Type a term to open and highlight every matching topic. Press Enter to step through the results.
- **Pan and zoom.** Drag to move, scroll or pinch to zoom, and use *Fit to screen* to recentre.
- **Light and dark themes.** The page follows your system setting and works on phones.

## How to use it

| Action | Result |
| --- | --- |
| Click a topic | Opens its details panel; expands the branch if it has subtopics |
| Click the selected branch again | Collapses it |
| Type in the search box | Highlights matching topics |
| Enter (in search) | Jumps to the next match |
| Esc | Clears the search or closes the panel |
| Expand all / Collapse | Opens or closes every branch |

## Areas covered

Security Operations · Using and Securing AI · Governance · Identity and Access Management · Team Management · Business Enablement · SDLC and Project Delivery Lifecycle · Security Architecture · Compliance and Audits · Legal · Risk Management · Automation and Analytics
